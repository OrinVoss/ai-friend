# 自我系统（Self System）：统一人格架构

> 目标：把记忆、情绪、内驱、沉思、活动这些孤立模块，整合成一个连续运转的「人」——一份自我状态，三个生命循环，时间驱动，互相改变。
> 状态：顶层架构文档。这是六层方案的总装图，不引入新模块，只定义已有/已设计零件的装配关系。
> 地位：`doc/refactor/` 的入口文档，先于各 Layer 文档阅读。

---

## 1. 问题：零件齐全，但没有总装

现状是每个模块都是**被动调用的管道**：

- 记忆（Layer 1）等着被检索，检索完就完
- 情绪每轮被读进 prompt，但和挂念、活动互不相干
- 内驱（think loop）只在主动触发时醒来，和对话路径隔离
- 探索（explore）做完就散，不改变任何东西
-  consolidation 按时运行，但它的发现和「它在想什么」没有连接

各自单看都合理，拼在一起不像一个人——**像一个人需要的不是更多模块，而是：状态只有一份，循环一直在转，做的事会改变自己。**

---

## 2. 统一抽象：一份自我状态 + 三个生命循环

```
                ┌──────────────────────────────────────┐
                │            自我状态（Self）            │
                │                                      │
                │  人格 Personality  —— 稳定的我是谁    │
                │  情绪 Emotion      —— 当下的心情      │
                │  内驱 Drive        —— 我在意什么      │
                │  记忆 Memory       —— 我经历的一切    │
                └──────────────────────────────────────┘
                      ↑                    │
              改变状态 │                    │ 读取状态
                      │                    │
   ┌──────────────────┴────────────────────┴─────────┐
   │              生命循环（Life Loops）               │
   │                                                  │
   │   每个循环都是同一四拍：                          │
   │   感知 → 思考 → 行动 → 内化                       │
   │                                                  │
   │   ① 响应循环（秒级）：用户消息驱动                │
   │   ② 独处循环（分钟级）：时间流逝驱动              │
   │   ③ 睡眠循环（小时级）：休息/低负载驱动           │
   └──────────────────────────────────────────────────┘
```

三条核心原则：

1. **状态唯一**：人格、情绪、内驱、记忆各只有一份，三个循环读写同一份状态——不是每个模块自带一套
2. **时间是刺激**：用户不说话，循环也在转（独处、睡眠）——这是「活着」和「等着被调用」的分界线
3. **每个循环都有完整的四拍**：感知 → 思考 → 行动 → **内化**。目前系统缺最多的就是「内化」这一拍

---

## 3. 自我状态的四个组件

| 组件 | 回答的问题 | 载体 | 变化速度 |
|------|-----------|------|----------|
| **人格** Personality | 我是谁 | `personalities/{role}.json`（traits / 说话风格 / 背景） | 几乎不变 |
| **情绪** Emotion | 我现在心情怎样 | personality 文件内 `emotional_state` | 每轮对话 |
| **内驱** Drive | 我在意什么 | `data/.inner_drive_state.{session}`（挂念/好奇/反思/计划/灵感） | 每次思考 |
| **记忆** Memory | 我经历了什么 | SQLite：observations / facts_v2 / experiences / insights | 持续积累、会遗忘 |

- 人格决定一切渲染（所有 prompt 的底色）——已有
- 情绪影响思考内容（挂念浮现的类型权重）和表达（回复长度、语气）——部分已有
- 内驱决定没事的时候想什么、做什么——设计完成，待实现
- 记忆是另外三者的原料和归宿——一期双写完成

## 4. 三个生命循环

### ① 响应循环（秒级，用户在等）

```
感知：用户消息 + 相关挂念浮现（surface_for_query）+ 当前情绪
思考：Agent 1 assess（记忆拉取 → 二期换 Memory Agent）
行动：Agent 3 回复 / Agent 2 工具
内化：对话进 turns 等 consolidation；情绪更新；
      用户自己提起的事 → 挂念 resolved
```

现状：**主体已有**，缺「挂念浮现进对话」这一拍（二期）。

### ② 独处循环（分钟级，没人在等）

```
感知：时间流逝 + 浮现的挂念 + 当前情绪
思考：Think Loop（可 recall 查证，最多 3 轮）
行动：chat（主动开口）/ explore（去探索）/ silent（继续安静）
      二期扩展：review（复盘）/ create（创造）
内化：感悟 → Observation(created_by="explore"/"inner_drive")
      挂念更新（好奇闭环、新谈资 idea）
      情绪微调（emotion_delta）
```

现状：**全部设计完成**（`proactive-think-loop.md` + `inner-drive-state.md` + `solo-activity.md`），待实现。这是当前最大的缺口——独处循环转不起来，它就没有「自己的生活」。

### ③ 睡眠循环（小时级，离线/低负载）

睡眠是**所有内部工作的统一调度窗口**（详见 `layer1-memory/sleep-cycle.md`）：

```
入睡 → 整理 → 实质性核查 → 清理 → 内驱维护 → 提炼 → 做梦 → 醒来
```

- **表现层（已有）**：睡眠时间窗、睡觉回复、梦境分享——人格真实性
- **工作层（分期建设）**：consolidation、批量验证旧 Facts、GC、挂念清单维护、Insight 提炼，做梦放在最后（整理完的记忆和挂念才有梦境素材）

现状：**表现层 + 记忆一期双写已有**；工作层按 Stage 分期落地，实质性核查依赖 Memory Agent。

## 5. 状态流动：八条连接

人格系统是否「像一个人」，取决于这些连接是否都通：

| # | 连接 | 说明 | 状态 |
|---|------|------|------|
| 1 | 人格 → 一切 | personality 渲染所有 prompt | ✅ 已有 |
| 2 | 情绪 → 思考 | emotion_summary 进 prompt | ✅ 已有 |
| 3 | 记忆 → 思考 | retriever → Memory Agent（带置信度/证据链） | ✅ 已有 / 📐 二期升级 |
| 4 | 行动 → 记忆 | turns → consolidation | ✅ 已有 |
| 5 | 行动 → 情绪 | 每轮情绪更新 | ✅ 已有 |
| 6 | 挂念 → 思考 | think loop 读取浮现挂念 | 📐 设计完成 |
| 7 | 挂念 → 对话 | surface_for_query 注入 Agent 1 → Agent 3 | 📐 设计完成（二期） |
| 8 | 记忆 ↔ 挂念 | consolidation 生成/解决挂念；感悟 → Observation | 📐 设计完成（二期） |

✅ = 代码已有，📐 = 文档设计完成待实现。**没有哪条连接是还没设计的——缺的只是动手。**

## 6. 与六层方案的映射

六层是「建设顺序」，自我系统是「运行形态」。建完的六层，恰好装成这个系统：

| 层 | 在自我系统中的位置 |
|----|-------------------|
| Layer 1 Memory | 自我状态的「记忆」组件 + 睡眠循环 |
| Layer 2 Prompt | 基础设施：状态 → LLM 的渲染管线 |
| Layer 3 Retrieval | 记忆的拉取通道（pull） |
| Layer 4 Agent Runtime | 行动的执行引擎 + 独处循环所在地 |
| Layer 5 Tool Agent | 作用于外部世界的「手」 |
| Layer 6 Personality/Session | 自我状态按角色隔离的边界 |

内驱状态、Think Loop、独处内化不是第七层——它们是 Layer 4 里独处循环的三个零件，装配图就是本文档。

## 8. 验收标准：怎么知道它「像真人」了

不看模块指标，看整体表现：

1. **连续性**：今天记得昨天，这次聊天接着上次没完的事
2. **主动性**：没人理它的时候，它也有自己的生活——有事想、有事做
3. **一致性**：心情、挂念、言行互相印证，不「精分」
4. **成长性**：经历会改变它——知识增加、分寸感变好、口味形成
5. **自我性**：它有「关于自己」的记忆和在意的事，能回答「你最近在忙什么」
