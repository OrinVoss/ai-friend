## 总览

| 周 | 重点 | 数量 | 关键风险 | 关键产出 |
|----|------|------|---------|---------|

## 使用方式

1. 每天挑选当天 issue，逐个修复
2. 每个 issue 修复后运行 `python -m pytest tests/ -v`
3. 当天修复完成后推送并关闭 issue
4. 每周结束时更新 milestones

## 不做的

- 全异步化（v1.0 范围）
- 前端重写（v1.0 范围）
- 独立 P2/P3 修复（顺带修，不单独开 PR）
