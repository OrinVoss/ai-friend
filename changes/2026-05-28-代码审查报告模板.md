### E. 数据流图参考

```
用户输入
    ↓
CLI (main.py) / WebSocket (web/server.py)
    ↓
Agent.process_message() / process_proactive()
    ↓
[PERCEIVE] → 短期记忆记录 + 检索长期记忆
    ↓
[THINK] → 构建系统提示词 → LLM generate → 解析 tool_call
    ↓
[ACT] → 有 tool_call? → 执行工具 → 结果注入 → 回到 THINK
     ↓ 无 tool_call
[REFLECT] → 情绪更新 → consolidation → 回到 IDLE
```

### F. 双代码路径问题

**Agent 核心当前存在两套 ReAct 实现路径：**

| 路径 | 方法 | 使用场景 | 行数 |
|------|------|---------|------|
| 路径 A | `_react_loop()` | WebAgent / 单次 process_message 调用 | ~30 行 |
| 路径 B | `_on_think()` + `_on_act()` | CLI `run()` 状态机循环 | ~80 行 |

潜在问题：两路径逻辑不同，路径 A 在 `_react_loop()` 中流式输出仅第一次迭代开启，路径 B 也在第一次迭代开启流式但需处理 CLI 交互细节。
