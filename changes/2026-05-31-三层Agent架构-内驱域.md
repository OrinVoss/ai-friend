# 三层 Agent 架构：内驱域 + 工具调用 + 情感表达（#107）

**时间**：2026-05-31

## 架构

```
用户 → Agent 1 (内驱域) → Agent 2 (工具调用) → Agent 3 (情感表达) → 回复
         │                    │                      │
         自知+知彼+决策       纯工具+重试             角色+人格+工具结果
         recall/remember      7 external tools        recall/remember only
```

### Agent 1: 内驱域 Agent
- 推理循环：感知用户输入 → 检索记忆 → 识别信息缺口 → 决策
- 不需要工具 → 直接到 Agent 3
- 需要工具 → 用自然语言表达工具请求（非 XML）

### Agent 2: 工具调用 Agent
- 接收自然语言请求 → 解析为 `<tool_call>` XML → 执行
- 重试机制：单轮最多 3 次，全局最多 3 轮 × 3 次 = 9 次
- 3 次全失败 → 回传 Agent 1 重新决策

### Agent 3: 情感表达 Agent
- 接收内驱决策摘要 + 工具结果
- 完整人格回复
- 工具失败如实告知，不编造

### 闲聊优化
- 旧架构（两阶段）：每条消息 2 次 LLM 调用（ToolAgent + Roleplay）
- 新架构：闲聊 1 次 LLM 调用（Agent 1 判断不需要工具 → 直接 Agent 3），工具消息 3 次

## 设计原则
- 内驱域 Agent 先思考再行动，不是盲目先调工具
- 自然语言桥接 Agent 1 和 Agent 2，降低 XML 耦合
- 重试+回传保证工具失败时有备用路径
- 闲聊场景减少 API 调用
