# 修复 #1 #2：Async SQLite + 结构化 JSON 工具调用

**时间**：2026-05-31

## #1：Async SQLite（aiosqlite）

替换 `threading.Lock + sqlite3` → `asyncio.Lock + aiosqlite`

### 修改文件

- `storage/database.py` — sqlite3 → aiosqlite；`cursor()` 变 async contextmanager；`open()` 和 `close()` 变 async；新增 `get_connection()`
- `storage/repository.py` — 全部方法 `async def`；`c.fetchall()` → `await c.fetchall()`
- `memory/long_term.py` — 底层方法 async + sync 兼容包装（`_run_sync`），现有调用代码无需修改
- `main.py` — `asyncio.run(main())` + `await db.open()`
- `web/server.py` — lifespan 中 `await session_manager.open()`
- `web/session.py` — `SessionManager.open()` async
- `requirements.txt` — 新增 `aiosqlite`

### 设计

- 底层 async，上层通过 `_run_sync()` 兼容包装保持同步
- ThreadPoolExecutor 处理 event loop 冲突场景
- Web 路径直接 async await，消除 `loop.run_in_executor`

## #2：结构化 JSON 工具调用

用 `response_format={"type": "json_object"}` + JSON Schema 约束替换 XML 正则解析。

### 修改文件

- `core/provider.py` — `generate()` 新增 `response_format` 参数
- `tools/traits.py` — `ToolRegistry.to_json_schema()` 生成 JSON Schema
- `core/dispatcher.py` — 三层解析：JSON `calls` 数组 → XML regex → bare JSON fallback
- `prompts/system.py` — `build_tool_agent_prompt()` 改为 JSON 格式指令
- `core/tool_agent.py` — Provider 调用传入 `response_format`

### JSON 格式

```json
{"calls": [{"name": "web_search", "arguments": {"query": "..."}}]}
```

不使用工具时：`{"calls": []}`
