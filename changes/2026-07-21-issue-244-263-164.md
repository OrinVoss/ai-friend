## T1（#244）：前端 Cookie SameSite=Lax

### 修改文件

- `web/static/app.js:81-87`
- `tests/test_web_startup.py`

### 内容

`setCookie` 与 `clearCookie` 的 cookie 串追加 `; SameSite=Lax`。

未加 `HttpOnly`（`session_id` 需要被 JS 读取后放进 WS init 消息）和 `Secure`（本地开发使用 http，Secure 会导致 cookie 无法写入），并在代码注释中说明决策。

### 新增测试

`TestCookieSameSite::test_session_cookie_has_samesite_lax`：读取 `web/static/app.js` 源码，断言 `setCookie` 与 `clearCookie` 两处都含 `SameSite=Lax`。

## T2（#263）：async_utils 超时取消传播

### 修改文件

- `core/async_utils.py`
- `tests/test_async_utils.py`

### 内容

有事件循环分支（Web 场景）的 `run_async` 超时时，通过 `call_soon_threadsafe(task.cancel)` 把取消传播进 worker 线程内的协程句柄，使协程的 `try/finally` 清理（如 DB rollback）得以执行，不再留下僵尸线程。

保留 `contextvars.copy_context()` 以继续传播 `request_id` 等上下文。

### 新增测试

- `TestRunAsyncRunningLoop::test_timeout_propagates_cancellation_into_coro`：在已有事件循环的线程里调用 `run_async`，断言抛出 `TimeoutError` 且协程 `finally` 块被执行。
- `TestRunAsyncRunningLoop::test_result_returned_with_running_loop`：有事件循环时正常完成路径不受影响。

## T3（#164）：记忆固化 LLM 调用合并

### 修改文件

- `memory/consolidation.py`
- `prompts/templates.py`
- `config.py`
- `config.example.json`
- `doc/config-reference.md`
- `tests/test_consolidation_unified.py`

### 内容

1. **解析逻辑抽出**：
   - `_extract_facts` → `_parse_fact_lines`
   - `_summarize_experience` → `_parse_experience_block`
   - `_generate_reflection_l1` → `_parse_insight_block`
   - 旧方法保留为"调用 LLM + 调解析函数"的薄壳，旧路径行为不变。

2. **统一 prompt**：新增 `CONSOLIDATION_UNIFIED_PROMPT`，输出 `FACTS:` / `EXPERIENCE:` / `INSIGHT:` 三段，一次 LLM 调用完成 L1 常规批次的事实提取、体验总结、L1 insight 生成。

3. **合并路径与灰度开关**：
   - `config.py` / `config.example.json` 新增 `consolidation_unified_call: bool = True`。
   - `MemoryConsolidator.consolidate()` 中，L1 常规批次且开关开启时走 `_consolidate_unified`。
   - L2/L3 节奏批次仍走旧三次调用路径，保持既有语义。

4. **容错**：
   - 分段缺失/解析失败只跳过该段，记 warning 并记入 `errors`。
   - 统一输出完全无法解析时，本批整体回退到旧三次调用路径，不丢数据。

### 新增测试

`tests/test_consolidation_unified.py`：

1. `test_unified_path_persists_all_three_with_one_llm_call`：合并路径一次 LLM 调用，facts/experience/insight 各落库一次。
2. `test_unified_missing_insight_section_skips_insight`：缺 INSIGHT 段时其余两段正常落库并记 warning。
3. `test_unified_unparseable_fallback_to_old_path`：完全无法解析时回退旧路径，总调用 1+3 次，数据不丢。
4. `test_unified_disabled_uses_old_path`：开关关闭时完全走旧路径。
5. `test_l2_turn_uses_old_path`：L2 节奏批次走旧路径，L2 insight 正常触发。
6. `test_l3_turn_uses_old_path`：L3 节奏批次走旧路径，L3 insight 正常触发。
