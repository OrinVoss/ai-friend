# 2026-07-26 前端界面升级（双主题 + 视觉精修 + 交互增强）

## 修改原因

升级 Web 前端界面观感与交互体验。约束：克制，不新增任何后端节点/接口，仅复用现有 WS 与 REST API。

## 修改的文件

- `web/static/theme.css`（新增）
- `web/static/style.css`（重写）
- `web/static/index.html`
- `web/static/app.js`（重写）
- `web/static/monitor.html`
- `web/static/monitor.js`（仅头部加主题初始化，逻辑不动）
- `CLAUDE.md`（同步 CSS 变量所在文件的描述）

## 修改内容摘要

### 双主题（theme.css）

- 新增共享设计令牌：语义色板、圆角/阴影/过渡梯度、监控页专用 `--monitor-*` 变量。
- 主题机制：`<html data-theme="light|dark">` 手动指定，未指定时经 `prefers-color-scheme` 跟随系统；`color-scheme` 同步切换原生控件配色。
- 手动选择存 `localStorage.ai_friend_theme`，主界面与监控页共用同一 key。

### 视觉精修（style.css）

- Header 毛玻璃（backdrop-filter）、用户气泡改为蓝紫渐变、气泡圆角/阴影精修、输入框 focus 光晕、面板卡片化、全局统一细滚动条、Markdown 表格样式、弹窗毛玻璃遮罩、`prefers-reduced-motion` 降级。
- 全部颜色改为 `var(--*)`，无硬编码色值。

### 交互增强（app.js / index.html）

- 主题切换按钮（header 右侧，太阳/月亮图标，持久化 + 跟随系统变化监听）。
- 流式渲染：WS `segment` 到达即增量 `marked.parse` 渲染（失败回退纯文本），流式气泡带闪烁光标，`done` 终渲染；只向带 `data-raw` 的流式气泡追加，避免误拼到上一条消息。
- 智能滚动：贴底才自动跟随；用户上翻时不再强拉，显示"回到底部"悬浮按钮并累计新消息角标。
- 消息操作条：悬停显示复制按钮（clipboard API + execCommand 兜底，成功短暂变"已复制"）；实时消息显示 `HH:MM` 时间戳（历史接口无时间字段，历史消息不显示时间）。
- 空态引导（无历史时显示角色头像 + 提示）、历史加载骨架屏（shimmer 动画）、WS 断开/重连期间顶部断线横幅。
- 静态资源版本号 `?v=14` → `?v=15`。

### 监控页统一（monitor.html）

- 引入 theme.css，内联样式全部改用语义变量，深浅色自动跟随；因服务端 CSP `script-src 'self'` 禁止内联脚本，主题初始化放在 `monitor.js` 头部（约 8 行）。
