# 添加音乐播放工具

**时间**：2026-05-29

## 修改文件

- `tools/music_tool.py` — 新增 MusicListTool + MusicPlayTool
- `main.py` / `web/session.py` — 注册两个新工具

## 新增工具

| 工具 | 功能 |
|------|------|
| `music_list` | 浏览 D:\音乐 目录，列出子目录和歌曲（支持搜索） |
| `music_play` | 播放歌曲，自动搜索匹配文件名，支持精确路径 |

播放器：Windows Media Player COM 对象（PowerShell 调用），fallback 到默认播放器。

## 工具总数：8 个

recall / remember / read_file / notify / web_search / web_fetch / music_list / music_play
