# 多请求工具结果归因

## 修改文件

- `core/tool_agent.py`
- `core/dispatcher.py`
- `tests/test_tool_agent.py`

## 修改原因

Agent 2 的 `run_with_requests` 并发执行多个工具请求后，合并结果丢失"哪条记录属于哪个请求"的信息。当请求 2 成功、请求 1 失败时，Agent 3 无法向用户说清"哪件事没办成"。

## 修改内容摘要

1. `core/tool_agent.py`：
   - `ToolCallRecord` 增加 `request: str = ""` 字段（末尾、带默认值，兼容旧构造）。
   - 新增 `_truncate_request()` 辅助函数，将自然语言请求截断到 80 字符。
   - `run()` 与 `run_with_request()` 在创建记录时填入当前请求文本。
   - `format_for_phase2()` 在存在两个及以上不同 `request` 时按请求分组渲染，每组前加标题 `【请求：...】`；单请求时保持原格式不变。

2. `core/dispatcher.py`：
   - `format_tool_results()` 增加可选参数 `append_iron_rule: bool = True`（默认保持原行为）。多请求分组时只对最后一组附加铁律段，避免重复。

3. `tests/test_tool_agent.py`：
   - 新增 `test_format_for_phase2_single_request_unchanged`：单请求格式不变。
   - 新增 `test_format_for_phase2_multi_request_groups`：多请求分组、成功/失败归属正确、铁律段只出现一次。

## 验证

- `python -m pytest tests/test_tool_agent.py tests/test_dispatcher.py -q` → 67 passed。
