# 破防初始值根据情绪状态设置

**时间**：2026-05-28

## 修改文件

- `core/agent.py` — Agent.__init__ 中根据当前情绪状态预设 _consecutive_negative

## 修改原因

破防需要连骂 5 次触发，但 AI 已经处于极端负面状态时，应该开局就接近破防线，不需要从头开始。

## 修改内容

```python
neg_score = max(e.anger, e.sadness, e.disgust)
if neg_score > 0.8:    → _consecutive_negative = 4  (差一句破防)
elif neg_score > 0.5:  → _consecutive_negative = 2
else:                  → _consecutive_negative = 0
```
