# 优化主动对话和探索的话题选择

**时间**：2026-05-29

## 修改文件

- `core/agent.py` — `_pick_proactive_topic()` 不再兜底"随便聊聊"
- `core/agent.py` — `process_explore()` 探索提示锚定用户兴趣
- `prompts/system.py` — explore_mode 提示词要求搜相关内容

## 修改内容

话题来源优先级：
1. 最近聊过的话题（最有上下文）
2. 用户相关的事实
3. 用户兴趣标签（personality.json interests）
4. 时间段兜底（早上→今天计划，中午→吃了什么，深夜→今天过得怎么样）

探索模式不再自由发挥，锚定在用户兴趣上。
