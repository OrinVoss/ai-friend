# 修复主动回复循环触发导致刷屏

**时间**：2026-05-28

## 修改文件

- `core/agent.py` — `_react_loop` 新增 `add_to_history` 参数
- `web/server.py` — `_proactive_loop` 重置计时器 + 冷却计数

## 修改原因

Fix #59：Web 端无用户操作时，AI 持续发送主动消息形成刷屏。

两个根因：
1. 主动回复后未重置 `last_activity_time`，每 15 秒重复触发
2. 主动回复被加入 `short_term`，后续主动对话看到之前的回复形成自言自语链

## 修改内容

1. `_react_loop(add_to_history=True)` — 控制是否将回复写入短期记忆
2. `process_proactive` 传入 `add_to_history=False`
3. `_proactive_loop` 发送主动消息后 `last_activity_time = time.time()`
4. 新增 `cooldown` 计数器（12 × 5s ≈ 3 分钟冷却）
