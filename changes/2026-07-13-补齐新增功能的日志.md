# 补齐新增功能的日志

## 背景

今天新增的角色/session 绑定、关系指标隔离、状态/角色 API 等功能在运行日志里能见度不足，排查问题时难以确认是否被调用、返回了什么数据。本次改动为关键路径补日志，不修改业务逻辑。

## 改动

- `storage/repository.py`
  - `get_all_relationships` / `get_relationship_history`：debug 日志输出 session 与返回行数
  - `ensure_relationship_defaults`：info 日志输出实际插入的默认维度
  - `set_session_role` / `get_role_for_session` / `get_sessions_by_role`：debug/info 日志输出 session/role 映射
  - `search_experiences` / `get_recent_experiences` / `get_recent_reflections`：debug 日志
  - `update_fact_score` / `increment_fact_recall` / `update_experience_score`：debug 日志

- `web/server.py`
  - `/api/status` / `/api/roles` / `/api/sessions` / `/api/chat/history`：info 日志输出调用参数

- `memory/consolidation.py`
  - `_update_relationship`：info 日志汇总输出本次更新的维度与情绪

- `web/session.py`
  - `_ensure_relationship_defaults`：debug 日志确认已执行

## 验证

- `python -m py_compile storage/repository.py web/server.py memory/consolidation.py web/session.py` 通过
