**日期**: 2026-05-31  
**审查范围**: core/tool_agent.py, core/dispatcher.py, tools/traits.py, core/inner_drive.py, core/message_handler.py, core/agent.py, core/cli_controller.py, prompts/system.py

## 修改的文件

- `doc/round02-tool-call-flow.md` — 新增第2轮深度代码审查报告

## 修改原因

对 AI Friend 三层 Agent 架构中的工具调用完整数据流进行深度审查，跟踪从 Agent 1 内驱推理 -> Agent 2 外部工具执行 -> 结果返回 -> Agent 1 review -> Agent 3 消费的完整链路，识别数据流断裂、状态不一致、重试逻辑缺陷等问题。

## 审查发现摘要

### 高优先级问题（11项）

1. **Agent 1 工具隔离缺陷** (`core/inner_drive.py:99`): Agent 1 使用 `full_registry` 执行内部工具，无运行时防护阻止外部工具直接执行，破坏架构隔离。
2. **Agent 2 retry last_failure 未更新** (`core/tool_agent.py:183-186`): 当 `parse_tool_calls` 返回空时，`last_failure` 未更新，retry prompt 信息错误。
3. **Agent 2 结果传递错误** (`core/message_handler.py:155-156`): `_run_agent3()` 接收最后一轮 `tool_result` 而非累积结果，导致前面轮次成功结果丢失。
4. **ToolAttemptTracker 完全失效** (`core/message_handler.py:104`): `round_number` 永远是 0，tracker 每轮新建，状态不共享，3x3 重试设计未实现。
5. **Agent 2 Provider 异常未捕获** (`core/tool_agent.py:181-182`): `provider.generate()` 无 try-except，异常导致整个消息处理中断。
6. **asyncio.run() 循环调用** (`core/dispatcher.py:128-133`): 在循环中调用 `asyncio.run()`，性能差且在某些环境会崩溃。

### 中优先级问题（13项）

- ToolCallRecord.arguments 永远为空
- _tool_call_history 不记录 Agent 2 调用
- Agent 1 review 新记忆对 Agent 3 不可见
- Web/CLI 路径 Agent 3 工具权限不一致
- failure_log 不完整（不记录"无工具调用"失败）
- 等等

### 低优先级问题（5项）

- EXTERNAL_TOOL_NAMES 重复定义
- _tool_call_history 并发截断风险
- format_for_phase2 多轮结果重复头部
- 等等

## 风险评级

**整体风险评级：中高风险**

建议优先修复高优先级问题（Agent 1 工具隔离、Agent 2 retry 逻辑、结果传递、ToolAttemptTracker、Provider 异常捕获），然后逐步处理中优先级问题。
