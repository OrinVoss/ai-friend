# 修复 issue #370：llama-server 不随主进程退出

## 修改的文件
- `core/embedding_server.py`

## 修改原因
CLI/Web 退出时不 terminate 拉起的 llama-server，子进程脱离存活，白占内存/显存。

## 修改内容
- `auto_start_embedding` 真正拉起 server 后注册 atexit：主进程退出时 `kill_existing_llama`。
- 共享实例（"already running" 路径）不注册，不归我们管。
- 验证：`pytest -k embed` 50 passed, 2 skipped。
