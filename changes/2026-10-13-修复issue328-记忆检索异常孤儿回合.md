# 修复 issue #328：记忆检索异常产生孤儿回合且 turn_no 重复

## 修改的文件
- `core/message_handler.py`

## 修改原因
user turn 在 :292 先落库（用当前 turn_count 作 turn_no），turn_count 到 _react_loop 末尾才自增；中间的 `_context_for_state`（记忆检索）不在任何 try 内，抛错会留下无回复的孤儿回合，且下条消息以同一 turn_no 写入，历史损坏。

## 修改内容
- `_context_for_state` 调用包 try/except，异常时记 warning 并降级为空记忆上下文（`"", 0.0, None`），流程继续走 Agent 3 正常回复——与 #146 的 Agent 1 降级先例一致。
- 验证：`pytest -k "message_handler or handler"` 48 passed。
