# Layer 2 Prompt 收尾：load_config 去重、缓存命中率监控、Agent 3 块评估

**时间**：2026-07-21

## 修改文件

- `config.py` — 默认路径 `load_config()` 增加进程级缓存；新增 `reload_config()` 强制重载
- `tools/file_tools.py` — 自动受益于 `load_config()` 缓存，减少重复磁盘读取与日志
- `core/prompt_cache.py` — 新增 `hits`/`misses`/`saved_chars` 计数器、`stats()`/`reset_stats()`/`maybe_log_stats()`
- `core/message_handler.py` — 每次 `build_system_prompt` 后输出 prompt cache stats
- `core/inner_drive.py` — 每次 `build_inner_drive_prompt` 后输出 prompt cache stats
- `tests/test_config.py` — 新增 `TestLoadConfigCache` 覆盖缓存命中、重载、自定义路径绕过
- `tests/test_prompt_cache.py` — 新增命中/未命中/节省字符数/stats/每 50 次 info 日志测试
- `doc/refactor/layer2-prompt/progress.md` — L2-1/L2-2/L2-3 打勾并写入 Agent 3 块级评估结论

## 修改原因

依据 `doc/refactor/layer2-prompt/tail-plan.md` 完成 Layer 2 收尾三项任务：

1. **L2-1 `load_config()` 去重**：工具层每次调用都读盘打日志，生产环境一条消息出现多次 `[config] loaded`。默认路径增加进程级缓存，自定义路径仍绕过缓存保证测试隔离。
2. **L2-2 Prompt Cache 命中率监控**：此前只有 hit/miss 日志，无法量化 #160 收益。新增计数器和 stats 方法，每 50 次总调用输出一次 info 级统计，其余 debug 级避免刷屏。
3. **L2-3 Agent 3 prompt 块必要性评估**：基于默认人格和典型记忆/对话样本，量化各块占比并形成结论，不改代码。

## 关键结论

- `load_config()` 默认路径首次加载后返回同一 `Config` 实例，`reload_config()` 可清缓存。
- Prompt Cache 累计命中字符数、命中率可观测；`MessageHandler`/`InnerDriveAgent` 每次 prompt build 后自动输出。
- Agent 3 各块评估结论：**全部保留**。`experiences`（共同回忆）是 memory 块内最大部分（样本中约占总 prompt 6.8%），但提供叙事连续性；若未来 token 紧张可优先压缩其上限，本次不改。
