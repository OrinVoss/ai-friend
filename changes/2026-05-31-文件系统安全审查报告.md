# 文件系统安全审查报告

## 修改文件

- 新建 `doc/round03-filesystem-security.md`

## 修改原因

执行第3轮安全性审查，聚焦文件系统访问安全。

## 修改内容摘要

对 AI Friend 项目的文件系统访问安全进行全面审查，覆盖以下8个维度：

1. ReadFileTool的路径白名单机制
2. 路径遍历攻击防御（../, 符号链接）
3. GlobTool和GrepTool的目录遍历风险
4. 文件读取的权限边界
5. 二进制文件检测
6. 文件大小限制
7. 写入操作的风险
8. Windows vs Linux路径安全差异

### 最严重的两个漏洞

1. **`os.path.abspath()` 不解析符号链接**: `_path_in_allowed()` 和 `_resolve_search_path()` 使用 `os.path.abspath()` 而非 `os.path.realpath()`，导致 Windows junction point / 符号链接可绕过白名单目录限制，读取系统敏感文件。

2. **`GlobTool` 遍历 junction point 目标目录**: `os.walk()` 会进入 junction point 指向的目录，导致目录结构泄露和潜在的 DoS。

报告包含详细的代码修复示例和按优先级排序的修复建议。
