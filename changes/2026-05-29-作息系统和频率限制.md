## 作息系统

| 事件 | 时间窗口 | 触发条件 |
|------|---------|---------|
| 午睡 | 12:00-13:00 | 情绪驱动（sad/melancholy +30%，excited/joyful -20%，resentment +20%） |
| 午睡醒 | 13:10-16:00 | 随机，arousal 高醒得早，resentment 高醒得晚 |
| 夜睡 | 23:30-次日 0:30 | 情绪驱动 + baseline 30% |
| 晨醒 | 7:00-10:00 | 随机，情绪影响 |

- 睡前发一条消息（"我去午睡了..." / "晚安"）
- 醒来分享梦境内容

## 频率限制

| 行为 | 上限 | 
|------|------|
| 探索 | 1 次/小时 |
| 聊天 | 2 次/小时 |
| 梦境 | 每次睡眠 1 次 |

## 梦境生成

LLM 基于最近事实 + 经历 + 情绪生成碎片化梦境（1-2 句，第一人称），存储为情绪事件。
