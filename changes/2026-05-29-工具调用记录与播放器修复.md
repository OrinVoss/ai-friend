# 工具调用记录与音乐播放器修复

**时间**：2026-05-29

## 修改文件

- `core/agent.py` — 新增 `_tool_call_history` 列表，每次工具调用自动记录
- `prompts/system.py` — 新增工具调用记录注入 prompt + 新工具使用提示
- `tools/music_tool.py` — 播放器改用 `os.startfile`（默认播放器）

## 新增功能

### 工具调用记录
- `_react_loop` 中每次执行工具后记录到 `_tool_call_history`（最多 20 条）
- 注入系统 prompt，AI 可告知用户"我刚才调用了什么工具、结果如何"
- 解决 AI 声称"调用了但实际没调"的幻觉问题

### 工具使用提示
- 提示词新增使用说明：web_search 主动用别反问、搜不到换关键词、music_play 模糊搜索自动匹配

### 音乐播放器
- 从 COM 对象/PowerShell 改回 `os.startfile`——用系统默认播放器
