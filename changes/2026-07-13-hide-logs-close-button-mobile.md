# 移动端隐藏日志面板关闭按钮

## 问题
移动端日志面板顶部有一个 `✕` 关闭按钮。在移动布局下，用户通过底部 tab 切换回聊天即可，关闭按钮多余且容易误触。

## 改动
- `web/static/style.css`
  - 在 `@media (max-width: 900px)` 下新增 `.logs-panel .panel-close { display: none; }`。
  - 状态面板（左侧）的关闭按钮保留不变。
- `web/static/index.html`
  - 静态资源缓存版本号从 `?v=5` 提升到 `?v=6`，确保移动端加载新样式。

## 效果
手机/小屏设备上打开日志面板时，顶部不再显示关闭按钮，用户通过底部 tab 切回「聊天」即可。

## 验证
- 在浏览器开发者工具中切换到移动端视口（宽度 <= 900px）。
- 打开日志面板，确认顶部 `✕` 按钮不显示。
- 状态面板顶部 `✕` 按钮仍然可见。
