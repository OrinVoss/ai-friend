# 主动对话空闲阈值与情绪挂钩

**时间**：2026-05-29

## 修改文件

- `core/agent.py` — `_calculate_proactivity` 新增情绪驱动的空闲阈值
- `web/server.py` — 硬编码 min_idle 改为 30s 绝对底线

## 修改内容

空闲阈值不再固定 180s，而是根据当前情绪动态变化：

| 情绪 | 阈值 | 
|------|------|
| excited | 60s |
| joyful | 90s |
| engaged | 180s |
| neutral | 360s |
| sad | 900s |
| angry | 480s |
| +resentment | 额外 +最高 300s |

`_calculate_proactivity` 在 idle < 阈值时直接返回 0.0，不触发。
