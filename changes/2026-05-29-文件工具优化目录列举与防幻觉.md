# 文件工具优化：目录列举 + 防幻觉规则 + 白名单统一管理

- `tools/file_tools.py` — read_file 支持目录列举，白名单从 config 读取
- `tools/search_tools.py` — glob/grep 白名单从 config 读取

### 防幻觉
