# Fix: Agent 3 工具结果如实汇报

**时间**：2026-06-01

## 问题

Agent 2 正确执行了工具（glob 等），但 Agent 3 收到真实工具结果后仍然编造内容——文件数量正确但具体名称和描述是编造的。

## 根因

工具结果放在系统提示中作为 Block 1 注入。LLM 在角色扮演模式下（"你是小星，嘴要贱心要暖..."），系统提示中的内容优先级低于角色指令，模型会自行润色/补充。

## 修复

**核心思路**：工具结果不放在 system prompt 中，而是作为单独的 **USER 消息** 注入。LLM 对 user role 消息的遵从度远高于 system 消息。

```
之前：system prompt（含 tool_records）+ user message → Agent 3
现在：system prompt + tool_records as USER message + user message → Agent 3
```

## 修改文件

- `core/message_handler.py` — `_run_agent3()` 中，`build_system_prompt()` 不再传入 `tool_records`，改为 `messages.insert(-1, {"role": "user", "content": tool_records})`
- `core/tool_agent.py` — `format_for_phase2()` 增强：显示调用次数、每条记录条目数、总条目数、更强的"禁止编造"约束
- `prompts/system.py` — Block 7 移除"外部内容已由系统自动获取"提示（不再需要）

## 效果

- Agent 3 将工具结果视为"用户提供的真实数据"，而非"系统提示中可以忽略的背景"
- 模型仍可保持角色回复风格，但事实部分必须基于 USER 消息中的真实数据
