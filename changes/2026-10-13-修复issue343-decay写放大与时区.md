# 修复 issue #343：lifecycle.decay N+1 写放大 + 时区混用退化

## 修改的文件
- `storage/repository.py`
- `memory/lifecycle.py`
- `tests/test_memory_lifecycle.py`

## 修改原因
1. `decay()` 逐条 `decay_fact_v2` + `update_fact_v2_status`，每条都是"抢锁→开游标→UPDATE→commit"，1000 条 facts = 上千次事务。
2. `now = datetime.utcnow()`（naive）与含 Z/偏移的 `last_verified_at`（aware）相减抛 TypeError 被吞，`days_since_verified=0`，永远恒定 0.99 衰减。

## 修改内容
- repository 新增 `decay_facts_v2_batch(items, decayed_ids)`：单游标一次 commit 完成全部衰减与状态翻转。
- `decay()` 统一 aware UTC：now 缺省用 `datetime.now(timezone.utc)`，naive 输入归一；`last_verified_at` naive 串按 UTC 处理。
- 测试改用批量 API 断言。
- 验证：`pytest -k "lifecycle or decay"` 37 passed。
