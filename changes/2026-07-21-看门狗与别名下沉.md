# M-18 embedding 看门狗 + KI-1 dispatcher 别名下沉

日期：2026-07-21

## 1. M-18：llama-server 崩溃自动重启

**问题**：`auto_start_embedding()` 的 watcher 线程在服务就绪后即退出，llama-server 之后崩溃无人处理，只能靠 retrieval 每消息探活降级到关键词检索，需人工重启才能恢复语义检索。

**改动**（`core/embedding_server.py`）：

- 新增 `_watchdog_loop()`：就绪后持续守护——每 30s 探活（`WATCHDOG_INTERVAL`），连续 3 次无响应（`WATCHDOG_FAIL_THRESHOLD`，容忍瞬时抖动）则 `kill_existing_llama()` + 重启；重启后就绪则计数清零；连续 3 次重启失败（`WATCHDOG_MAX_RESTARTS`）则放弃并保持关键词检索降级，日志提示手动重启应用恢复。
- 新增 `_wait_ready_quiet()`（无日志的就绪等待）与 `_watch_then_guard()`（启动 watcher 就绪后交接给 watchdog）。
- `auto_start_embedding()` 的 watcher 线程目标改为 `_watch_then_guard`。
- **边界**："server already running"（非本进程拉起的实例）不挂 watchdog——不归本应用管。

**测试**：`tests/test_embedding_server.py::TestWatchdog`（3 用例：达阈值触发一次重启、瞬时抖动容忍、连续重启失败放弃）。

## 2. KI-1：dispatcher 全局别名下沉到各工具

**问题**（known-issues #1）：`core/dispatcher.py::_normalize_args()` 对所有工具做统一别名映射，曾把 notify 的 `title` 当成 music 的 `song` 吃掉；且对 grep 等工具全局映射（search→query）反而让规范参数（pattern）丢失。

**改动**：

- `tools/traits.py`：`Tool` 基类新增 `ALIASES: dict[str, tuple[str, ...]] = {}` 类属性与 `normalize_args()` 方法（规范名已存在时别名不生效）。
- 各工具声明自己的别名：
  - `WebSearchTool` / `RecallTool`：`query ← search/keyword/question`
  - `GrepTool`：`pattern ← query/search/keyword/question`、`path ← filepath/filename/file/directory/dir/folder`（顺带修正了全局时代 search→query 导致 grep 拿不到 pattern 的问题）
  - `GlobTool` / `ReadFileTool` / `FileTreeTool`：`path ← filepath/filename/file/directory/dir/folder`
  - `MusicPlayTool`：`song ← song_name/track/title`（execute 内回退保留）；`MusicListTool`：`search ← query/keyword/question`
  - `NotifyTool` 无需声明（execute 内已有 content/text/msg/body 回退）
- `core/dispatcher.py`：删除全局 `_normalize_args` 及 3 处解析期调用；`_execute_single` 在权限检查后、参数校验前调用 `tool.normalize_args(args)`，required 校验看到的是规范参数名。废弃无人使用的 `person/who/user/target→name` 与 `text/msg/content→content` 全局组。

**测试**：`tests/test_dispatcher.py::TestNormalizeArgs` 重写（8 用例：per-tool 别名、grep pattern 修正、规范名优先、notify title 回归守卫、无别名透传、dispatcher 执行前归一）。

**文档**：`doc/tool-development.md`（第 3 步改为 ALIASES 声明）、`doc/technical.md`（别名归一化小节）、`doc/known-issues.md`（#1 标记根治）、`doc/deployment.md`（看门狗小节）。
