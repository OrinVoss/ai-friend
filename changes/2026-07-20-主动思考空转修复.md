# 修改记录：主动思考空转烧 Token 修复（2026-07-20）

依据 `doc/fix-plan-2026-07-20-proactive-token-drain.md`，逐项实施 F1-F6 修复方案。

## 修改的文件

### F1（P0）：silent 决策加指数退避冷却

- **core/proactivity.py**
  - `__init__`: 增加 `_consecutive_silents` 属性
  - `_load_state` / `_save_state`: 持久化 `_consecutive_silents`
  - 新增 `record_silent()`、`reset_silents()`、`silent_cooldown_seconds()` 方法
    - 退避序列：60→120→240→...→1800s（封顶）

- **core/runtime_driver.py**
  - `__init__`: 增加 `_next_decision_after` 时间戳门控
  - `run()`: 在 `calculate_proactivity` 前加入冷却检查
  - silent 分支：调用 `engine.record_silent()` + 设置 `_next_decision_after`
  - 响应分支：调用 `engine.reset_silents()` + 清除冷却

- **core/agent.py**
  - 新增 `record_silent()`、`reset_silents()`、`silent_cooldown_seconds()` 转发到 ProactivityManager

- **core/conversation_engine.py**
  - 新增 `record_silent()`、`reset_silents()`、`silent_cooldown_seconds()` 转发到 Agent

### F2（P0）：沉思循环成本收敛

- **config.py**: `proactive_think_max_rounds` 默认值 3→2
- **core/inner_drive.py**: 构造函数参数默认值 3→2
- **config.example.json**: `"proactive_think_max_rounds": 3` → `2`
- **doc/config-reference.md**: 更新默认值和说明
- **prompts/system.py**: `build_inner_drive_proactive_prompt` 中添加硬约束："如果没有真正值得开口的事，第一轮就直接给 silent 决定，不要用 recall 凑轮次"
- **tests/test_inner_drive.py**: `test_max_rounds_forced_termination` 期望值 3→2

### F3（P1）：空查询不再走 memory_agent

- **core/inner_drive.py**: `_context_summary_for` 开头增加空 query 检查，跳过 memory_agent 直接用 retriever
- **tests/test_memory_agent_integration.py**: 新增 `test_assess_proactive_skips_memory_agent_for_empty_query` 和 `test_assess_uses_memory_agent_for_nonempty_query`

### F4（P1）：梦境不得当真实记忆反刍

- **prompts/system.py**（3 处格式化位置）
  - `_build_inner_memory_block`: dream tag → `【梦境，非真实事件】` 前缀
  - `_build_memory_block`: 同上
  - `build_inner_drive_proactive_prompt`: 内联经验格式化处加上前缀
  - 同函数的 think_loop 指令块增加约束："标记【梦境】的内容是梦，不是真实发生的事"

- **memory/memory_agent.py**: `_retrieve_parallel` 中 experience 证据内容加前缀

- **memory/retrieval.py**: `retrieve_by_recall_tag` 中 experience 格式化加前缀

### F5（P2）：沉默疲劳因子

- **core/proactivity.py**: `calculate_proactivity` 中增加 `fatigue` 修正项
  - 用户沉默 30 分钟内无影响
  - 之后线性增长，封顶 -0.3（score 下限 0.0 不变）

### F6（P2）：API 断连重试增强

- **core/provider.py**
  - 重试间隔：`2 ** attempt` → `min(2 ** attempt * 2, 15)`（1/2/4s → 2/4/8s）
  - 新增简易熔断：连续 3 次完全失败后 60 秒内直接抛出异常不发起 HTTP
  - 成功时计数器归零，自动恢复

### 测试调整

- **tests/test_inner_drive.py**: F2 断言的 call_count 期望值 3→2
- **tests/test_memory_agent_integration.py**: F3 的两个测试替换为新的空/非空 query 测试
