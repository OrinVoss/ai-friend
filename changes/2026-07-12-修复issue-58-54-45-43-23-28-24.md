## 修改原因

一次集中修复架构、安全、可配置性与代码质量相关的 7 个 GitHub issue：

- **#58** `main.py` 与 `web_main.py` 的 embedding server 启动代码高度重复。
- **#54** CSS 颜色全部硬编码，无法统一换肤。
- **#45** Web 层直接访问 `Agent` 的 `_xxx` 私有属性，破坏封装。
- **#43** REST API 使用 `dict` 接收请求，无类型校验。
- **#23** `DeepSeekProvider` 无抽象基类，依赖倒置不足。
- **#28** 系统提示词中的对话示例硬编码，无法配置。
- **#24** CORS 配置不够灵活，缺少速率限制，CSP 可细化。

## 修改内容摘要

### #58 Embedding server 代码复用
- 将 `_kill_existing_llama`、`_auto_start_embedding` 从 `main.py` / `web_main.py` 提取到新建的 `core/embedding_server.py`。
- 两个入口文件统一调用 `auto_start_embedding(logger)`，消除约 100 行重复代码。

### #23 Provider 抽象基类
- 在 `core/provider.py` 新增 `LLMProvider(ABC)`，声明 `generate(...)` 抽象方法。
- `DeepSeekProvider` 继承 `LLMProvider`。
- `core/agent.py`、`web/session.py` 中的类型提示从 `DeepSeekProvider` 改为 `LLMProvider`。

### #28 对话示例可配置化
- `config.py` 新增 `conversation_examples` 字段，默认加载与原先一致的 5 组示例。
- `prompts/system.py` 的 `build_system_prompt` 新增 `conversation_examples` 参数，动态渲染示例。
- 同步修复 `EmotionalState.emotion_events` 为 `deque` 时无法切片的问题（转换为 `list` 后再切片）。

### #54 CSS 变量化
- `web/static/style.css` 在 `:root` 定义背景、文字、强调色、状态色等 CSS 变量。
- 所有硬编码颜色替换为 `var(--xxx)`，保持当前暗色主题视觉不变。
- `web/static/index.html` 与 `web/static/app.js` 中的内联颜色改为引用 CSS 类，彻底消除硬编码颜色。

### #45 WebAgent 封装私有属性
- `web/session.py` 的 `WebAgent` 新增公共接口：
  - `last_activity`、`is_sleeping` property
  - `get_sleep_state()`、`generate_dream()`、`calculate_proactivity()`、`check_rate_limit()`、`record_rate_limit()`、`decide_proactive_action()`、`save_personality()`
- `web/server.py` 与 `SessionManager.cleanup_old/shutdown` 全部改用公共接口，不再直接访问 `agent.agent._xxx`。

### #43 REST API Pydantic 校验
- 新建 `web/schemas.py`，定义 `ChatRequest`、`ChatResponse`、`StatusResponse`、`HistoryResponse`。
- `web/server.py` 的 `/api/chat`、`/api/status`、`/api/chat/history` 改为 Pydantic 模型入参与返回类型，自动获得 422 校验。

### #24 CORS / 速率限制 / CSP 细化
- `config.py` 新增 `allowed_origins` 字段，CORS 默认 localhost 并允许用户追加来源。
- 新建 `web/rate_limit.py`，实现基于内存滑动窗口的限流中间件：
  - `/api/chat` 与 WebSocket 消息：30 次/分钟
  - `/api/status`、`/api/chat/history`：60 次/分钟
- CSP 中 `script-src` 移除 `'unsafe-inline'`，仅允许 `'self'`；`index.html` 的 CSP meta tag 同步更新。

### 测试
