# 网页端数据持久化

**时间**：2026-05-28 11:25

## 修改文件

- `web/session.py` — `process_message()` 和 `process_proactive()` 每次调用后保存 personality.json
- `storage/database.py` — 初始化时自动创建数据库目录 `os.makedirs()`
- `config.py` — 数据库默认路径从 `ai_friend.db` 改为 `data/ai_friend.db`

## 修改原因

网页端每次交互后情绪和记忆数据未持久化，重启后丢失。

## 修改内容

1. WebAgent 每次处理完消息后立即保存 personality.json
2. 数据库默认路径移入 data/ 目录
3. Database 初始化时自动创建目录
