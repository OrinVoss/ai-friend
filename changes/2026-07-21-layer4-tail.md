# Layer 4 收尾（L4-1 ~ L4-4 + L4-6a/b）

> 执行计划：`doc/refactor/layer4-agent/tail-plan.md`
> 日期：2026-07-21

## 完成项

### L4-1：Agent 公开方法封装

- `core/agent.py`
  - 新增公开 property：`tool_registry`、`tool_call_history`、`is_sleeping`、`compressed_summary`、`consecutive_negative`。
  - 新增公开方法 `pick_proactive_topic()`。
  - 为 `_react_loop()` 补 docstring，说明其是「编排入口，刻意公开」。
- `core/message_handler.py`
  - 将所有 `a._xxx` 访问替换为上述公开访问（保留 `_react_loop`）。
- `web/session.py`
  - `is_sleeping` property 改为使用 `self.agent.is_sleeping`。
- `tests/test_message_handler.py`、`tests/test_proactive_emotion_skip.py`
  - mock agent 的 setUp 同步切到公开属性/方法。
  - 新增 `TestAgentPublicAccessors` 轻量断言。

### L4-2：Agent 2 工具循环全局超时

- `core/message_handler.py`
  - 新增类常量 `AGENT2_TOTAL_TIMEOUT = 120.0`。
  - `__init__` 读取配置 `agent2_total_timeout_seconds`（默认 120）。
  - `_run_agent2()` 在循环开头用 `time.monotonic()` 检查 deadline，超时后设置 error 并 break 到 Agent 3 降级。
- `config.py`
  - 新增 `agent2_total_timeout_seconds: int = 120` 与校验（<1 则钳位到 120）。
- `config.example.json` / `doc/config-reference.md`
  - 补充新配置项说明。
- `tests/test_message_handler.py`
  - 新增 `test_run_agent2_total_timeout_falls_back`。

### L4-3：强化输入清洗

- `core/message_handler.py`
  - 重写 `_INJECTION_PATTERNS`：角色前缀、`ignore previous` 变体、`from now on`、中文忽略指令变体。
  - 命中整行替换为空，并记录具体 pattern 名。
- `tests/test_message_handler.py`
  - 新增 `TestSanitizeInput`，覆盖变体剥除与正常中文不受影响。

### L4-4：异常时向用户反馈

- `core/message_handler.py`
  - Agent 2 exception fallback 的 error_message 改为系统提示：「工具执行出现错误（类型），请如实告诉用户哪一步没做成，不要编造结果」。
- `tests/test_message_handler.py`
  - 新增 `test_run_agent2_exception_injects_error_prompt`。

### L4-6a：内驱状态反馈闭环

- `core/inner_drive_state.py`
  - 新增 `record_outcome(entry_id, positive)`：正反馈给同类型活跃条目 +0.05（封顶 1.0），负反馈 ×0.9；被驱动条目标记 `resolved` 并记录结果。
- `core/message_handler.py`
  - `__init__` 新增 `_last_proactive_care`。
  - `handle_proactive()` 通过 `surface_for_query` / 子串匹配归因到活跃挂念。
  - `handle_message()` 在下一条用户消息时调用 `analyze_sentiment` 判定正负，并调用 `record_outcome`。
- `tests/test_inner_drive_state.py`
  - 新增 `TestRecordOutcome`：正/负奖惩、封顶、resolved 记录、缺失 entry no-op。
- `tests/test_message_handler.py`
  - 新增 `test_proactive_outcome_recorded_on_user_reply`。

### L4-6b：memory_agent 来源写入 curiosity

- `memory/memory_agent.py`
  - `__init__` 新增可选 `inner_drive_state` 参数。
  - `verify_fact()` 检测到矛盾时，向 `inner_drive_state` 写入一条 `type="curiosity"` 条目。
- `core/message_handler.py`
  - `_ensure_memory_agent()` 将 `agent._inner_drive_state` 注入 MemoryAgent。
- `tests/test_memory_agent.py`
  - 新增 `test_verify_fact_contradiction_writes_curiosity`。
