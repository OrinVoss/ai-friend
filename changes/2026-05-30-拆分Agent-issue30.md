## 架构变化

```
拆分前：
  agent.py (784行) — God Class

拆分后：
  agent.py (223行) ── 核心引擎
  ├── context_manager.py   — 上下文窗口管理
  ├── sleep_manager.py     — 睡眠/唤醒系统
  ├── proactivity.py       — 主动行为引擎
  ├── cli_controller.py    — CLI 状态机 (main.py only)
  └── message_handler.py   — 消息入口 (Web + CLI shared)
```

## 设计原则

- **功能类聚**：一个模块 = 一个功能域，内部高内聚
- **转发而非重写**：Agent 保留转发方法，不改变外部 API
- **构造函数注入**：提取的类通过 __init__ 接收依赖
