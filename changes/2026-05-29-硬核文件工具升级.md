# 硬核文件工具升级：glob + grep + 增强 read_file

**时间**：2026-05-29

## 修改文件

- `tools/file_tools.py` — 增强 read_file：行号、行偏移、500KB、二进制检测
- `tools/search_tools.py` — 新增 GlobTool + GrepTool
- `main.py` / `web/session.py` — 注册新工具

## 工具升级

### read_file（增强）
- 自动添加行号（`L123|代码内容`）
- offset 改为行偏移（非字符偏移）
- limit 限制行数（默认 200，最大 2000）
- 文件大小上限 100KB→500KB
- 二进制检测（跳过非文本文件）
- 底部提示剩余行数 + 下次 offset

### glob（新增）
- glob 模式搜索文件（`**/*.py`、`src/**/*.rs`）
- 显示文件大小
- 按名称排序，最多 200 结果

### grep（新增）
- 正则表达式搜索文件内容
- 支持 glob 文件过滤 + 上下文行数 + 忽略大小写
- 自动跳过 __pycache__/.git/ node_modules
- 单文件最大 500KB，最多 50 结果
