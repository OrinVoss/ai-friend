# 修复通知工具：参数别名冲突 + 阻塞问题

**时间**：2026-05-29

## 修改文件

- `tools/notify_tool.py` — 改用 PowerShell toast 通知，独立线程执行
- `core/dispatcher.py` — 移除 `message→content` 别名，避免参数名冲突

## Bug 1：`_normalize_args` 把 `message` 改为 `content`

`core/dispatcher.py:143` 的别名映射 `("message"→"content")` 导致 notify 工具的 `message` 参数被自动重命名。工具内 `args.get("message")` 返回空字符串，触发"参数为空"错误。

修复：从别名列表中移除 `"message"`，保留 `text/msg/content`。

## Bug 2：MessageBox 阻塞服务器

`ctypes.windll.user32.MessageBoxW` 同步弹窗会阻塞整个服务器进程，用户未点击时所有请求卡死。

修复：改用 `PowerShell WinRT ToastNotification` + 独立线程执行，不阻塞。
