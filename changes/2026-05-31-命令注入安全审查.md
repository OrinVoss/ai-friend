# 命令注入安全审查报告

## 修改文件

- `doc/round03-command-injection.md` — 新增安全性审查报告

## 修改原因

执行第3轮安全性审查，聚焦命令注入风险。覆盖 `tools/` 目录全部工具、`core/dispatcher.py` 及相关调用链。

## 修改内容摘要

- 审查发现 **2 个高危漏洞、5 个中危漏洞、3 个低危问题、2 个信息项**
- 核心问题：
  1. **NotifyTool PowerShell 命令拼接注入**（高危）：`title`/`message` 直接 f-string 插入 PowerShell，单引号可破坏字符串字面量导致任意代码执行
  2. **GrepTool ReDoS**（高危）：用户提供的正则直接传递给 `re.compile()`，恶意模式可导致 CPU 100% 卡死
  3. **路径遍历与符号链接绕过**（中危）：`os.path.abspath()` 未解析符号链接，可绕过目录限制
  4. **MusicPlayTool `os.startfile()` 风险**（中危）：符号链接可绕过音频扩展名校验执行任意程序
  5. **web_fetch SSRF**（低危）：未限制内网地址访问
- 报告包含完整攻击链分析、利用示例、修复建议及优先级排序
