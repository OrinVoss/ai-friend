# 2026-07-26 CLI 界面升级（prompt_toolkit）

## 修改原因

升级 CLI 终端界面：视觉美化、过程反馈、输入体验、状态展示四个方向。
用户批准新增 prompt_toolkit 依赖（不加 rich）。

## 修改的文件

- `requirements.txt`：新增 `prompt_toolkit==3.0.51`。
- `ui/display.py`：集中调色常量；新增 `panel()`（CJK 对齐边框面板）、`rel_bar()`
  关系进度条、`separator()`、`print_status()` 阶段提示、`print_banner()` 新 banner、
  `print_help()`；`print_mood` 升级为 emoji+颜色映射。
- `ui/cli.py`：重写为 prompt_toolkit 输入层——PromptSession（FileHistory 历史、
  斜杠命令补全、AutoSuggestFromHistory、bottom_toolbar 状态栏、patch_stdout）；
  删除 NonBlockingInputReader 轮询线程；非控制台环境（管道/CI）回退普通 input()，
  非 tty 输出强制 UTF-8（GBK 无法编码框线/emoji）。
- `core/cli_controller.py`：主循环改用 `ui.read_input()`（删除 0.1s 轮询与手写
  提示符）；注入 `status_fn` 供底部状态栏；`/mood`、`/status`（面板+进度条+7d 趋势）
  升级；`_CliFrontend` 新增 `on_status`、主动消息加分隔线、睡觉回复加 💤。
- `core/message_handler.py`：`handle_message(..., on_status=None)`；`_transition`
  按阶段发射中文提示（想/翻工具箱/写回复），返回点与主动路径清除回调。
- `core/conversation_engine.py`：透传 `fe.on_status` 给管线。
- 测试：`tests/test_cli_display.py`（新增 12 用例）；`tests/test_unified_pipeline.py`
  主循环用例改写为 read_input 模式 + on_status 透传/阶段提示用例（+3）。

## 与计划的偏差

- 计划中的「思考 spinner 线程」未实现——管线透传的阶段提示行（她在想…/翻工具箱…/
  写回复…）已覆盖过程反馈，且无线程交错风险，更克制。
