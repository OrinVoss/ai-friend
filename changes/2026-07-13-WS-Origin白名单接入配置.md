# 2026-07-13 WS Origin 白名单接入 config.allowed_origins

## 现象

通过内网穿透域名（如 `http://fenbumap.w1.luyouxia.net`）访问时，
WebSocket 连接被服务端拒绝：`[ws] rejected origin: http://fenbumap.w1.luyouxia.net`。

## 根因

WebSocket 的 Origin 校验（`web/server.py:417`）硬编码只放行
`{"localhost", "127.0.0.1"}`，完全没有读取 `config.allowed_origins`（该配置
原本只用在 CORS HTTP 中间件上）。导致通过穿透域名访问时 WS 握手失败。

## 修复

1. `web/server.py`：WS Origin 白名单从硬编码 set 改为动态构建：
   - 始终包含 `localhost` / `127.0.0.1`
   - 从 `config.allowed_origins` 中提取所有来源的 hostname 追加进白名单
   - 提取逻辑：调用 `urlparse(origin).hostname`，只取主机名，忽略 scheme/port，
     兼容各种穿透域名格式。

2. `config.json`：新增 `allowed_origins` 字段，填入穿透域名
   `http://fenbumap.w1.luyouxia.net`。

## 修改文件

- `web/server.py` — WS Origin 校验改为动态白名单（硬编码 → config-driven）
- `config.example.json` — 新增 `allowed_origins` 配置示例
- `config.json` — 新增 `allowed_origins` 字段（用户侧手动配）
- `changes/` — 本记录
