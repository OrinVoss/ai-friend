# 本地向量语义搜索：Qwen3.5-0.8B GPU 嵌入引擎

**时间**：2026-05-31

## 概述

基于本地 Qwen3.5-0.8B-Q6_K.gguf（640MB，GPU CUDA 加速，512 维）和 llama.cpp 运行环境，为记忆系统引入语义搜索能力。将 user_facts、experiences、reflections 全部语义索引化，用混合评分替代纯关键词匹配。

## 架构

```
写入：consolidation → 批量编码 → SQLite BLOB（float32[512]）
查询：query → 编码 → 语义(0.6) + 关键词(0.4) 混合评分 → Top-K → LLM 重排序
```

## 新增文件

- `memory/embeddings.py`（120 行）— EmbeddingEngine（封装 llama-server `/v1/embeddings` API，L2 归一化，health_check）+ EmbeddingCache（SHA-256 LRU 缓存，max 1000 条）
- `start_embedding_server.bat` — GPU 启动脚本（-ngl 99，端口 8080，批量 512）

## 修改文件

- `storage/database.py` — user_facts/experiences/reflections 各加 `embedding BLOB` + `embedding_version INTEGER` 列
- `storage/repository.py` — upsert_fact/insert_experience/insert_reflection 新增 embedding 参数；新增 `bulk_update_embeddings()` 批量更新
- `memory/retrieval.py` — MemoryRetriever 新增 `_hybrid_score()`（语义 0.6 + 关键词 0.4），`_search_experiences_semantic()`；embedding 服务不可用时自动回退纯关键词
- `memory/consolidation.py` — `_embed_new_items()` 在 consolidation 后自动批量编码无 embedding 的新条目
- `memory/long_term.py` — store_fact/store_experience/store_reflection 透传 embedding 参数
- `config.py` — 新增 embedding_endpoint/embedding_dim/embedding_cache_size 配置
- `requirements.txt` — 新增 numpy>=1.24.0
- `main.py` / `web/session.py` — 初始化 EmbeddingEngine 注入 Retriever + Consolidator

## 设计原则

- **混合检索**：语义捕获泛化概念，关键词保留精确匹配（如人名）
- **批量编码**：一次 HTTP 请求编码多个文本，GPU 批量推理
- **L2 归一化**：存储前归一化，查询时直接点积 = 余弦相似度
- **优雅降级**：embedding 服务不可用时自动回退关键词评分，AI 仍正常工作
- **幂等嵌入**：`_embed_new_items()` 只处理 `WHERE embedding IS NULL` 的行
