# 2026-07-13 新增 LLM API 调用监控面板

## 改动

### 1. 监控核心 — `core/monitor.py`
新增 `MonitorBuffer` 类（线程安全的环形缓冲，保留最近 200 条记录），
以及便捷函数 `record_call()`。每条记录包含：
- 时间戳、模型名、耗时、温度、max_tokens
- system 消息预览（前 200 字）
- 用户消息预览（前 200 字）
- 完整响应（截断至 5000 字）
- 来源标记（assess/react/tool_agent/dream 等）

### 2. Provider 接入 — `core/provider.py`
`DeepSeekProvider.generate()` 每次成功调用后自动调用
`record_call()`，将请求/响应写入监控缓冲。

### 3. API 路由 — `web/server.py`
- `GET /api/monitor?limit=N` — 返回最近 N 条记录的 JSON
- `GET /api/monitor/clear` — 清空缓冲
- `GET /monitor` — 返回监控页面

### 4. 监控页面 — `web/static/monitor.html`
简洁暗色主题的单页应用，展示每次 API 调用的：
- 时间、模型、来源、耗时（颜色分级）
- 可展开查看 system prompt、用户消息、完整响应

## 访问方式
启动服务后打开 http://localhost:8000/monitor
