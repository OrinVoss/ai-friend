# 修复 issue #322：流式 JSON 解析静默吞错

## 修改的文件
- `core/provider.py`
- `doc/known-issues.md`

## 修改原因
`core/provider.py` 流式解析 SSE 行时 `json.JSONDecodeError` 被裸 `continue` 静默跳过，API 返回非标准行时数据丢失且零日志（known-issues #103-2 记录在案未修）。

## 修改内容
- 捕获 `JSONDecodeError` 时记 `logger.warning`（含截断至 200 字符的行内容）后继续跳过该行。
- `doc/known-issues.md` 第 2 条标记已修。
