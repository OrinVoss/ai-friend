# 修复前端 segment 独立气泡 + 添加 WebSocket 心跳

**时间**：2026-05-28 12:20

## 修改文件

- `web/static/app.js` — segment 追加到同一气泡、JSON.parse try/catch、30s 心跳、currentAssistantMsg 管理

## 修改原因

1. 每个 segment 创建独立消息气泡，一句回复被切成多条视觉消息
2. JSON.parse 无 try/catch，非 JSON 数据时整个处理中断
3. 无 WebSocket 心跳，连接断开无法及时发现
4. 状态管理变量初始化不完整

## 修改内容

- `currentAssistantMsg` 追踪当前 AI 消息，segment 追加到同一气泡
- `done` 时清空引用，下次发消息时重置
- `onmessage` 整体包 try/catch
- 30s 定时 ping 保持 WebSocket 活跃
- `sendMessage` 时重置 `currentAssistantMsg = null`
