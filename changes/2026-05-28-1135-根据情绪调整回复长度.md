# 根据情绪调整回复长度

**时间**：2026-05-28 11:35

## 修改文件

- `core/agent.py` — 新增 `_max_tokens_for_emotion()` 方法，`_react_loop` 传入动态 max_tokens
- `core/provider.py` — `generate()` 新增可选 `max_tokens` 参数

## 修改原因

模型输出长度固定为 512 tokens，应根据情绪动态调整，让回复更自然。

## 情绪→长度映射

| 情绪 | max_tokens | 感觉 |
|------|-----------|------|
| excited / joyful | 768 | 兴奋话多 |
| engaged / content / neutral | 512 (默认) | 正常 |
| anxious / afraid | 300 | 急促简短 |
| melancholy / sad | 256 | 沉默寡言 |
| frustrated / angry | 256 | 不耐烦 |
