# 添加 web_search 和 web_fetch 工具

**时间**：2026-05-29

## 修改文件

- `tools/web_tools.py` — 新增 WebSearchTool + WebFetchTool，使用 AnySearch API
- `main.py` — 注册两个新工具
- `web/session.py` — 注册两个新工具

## 修改内容

### WebSearchTool
- 后端：AnySearch API (`api.anysearch.com/mcp`，JSON-RPC 2.0)
- 支持自然语言搜索、时效性过滤 (day/week/month/year)
- API key 通过 `ANYSEARCH_API_KEY` 环境变量读取，匿名也可用

### WebFetchTool
- 后端：AnySearch `extract` API
- 自动提取网页正文内容

## 工具现状（6 个）

| 工具 | 功能 |
|------|------|
| recall | 回忆用户信息 |
| remember | 记住用户信息 |
| read_file | 读取本地文件 |
| notify | Windows toast 通知 |
| web_search | AnySearch 网络搜索 |
| web_fetch | 网页内容提取 |
