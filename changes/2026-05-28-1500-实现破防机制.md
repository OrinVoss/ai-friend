# 实现破防机制

**时间**：2026-05-28 15:00

## 修改文件

- `core/agent.py` — 添加连续负面追踪 + 修复情绪分析 bug
- `prompts/system.py` — 添加三级破防行为指令

## 修改原因

用户骂 AI 时 AI 毫无反应，没有累积伤害效果。需要实现真正的"破防"——持续攻击后会委屈/崩溃。

## 修改内容

### agent.py

1. 新增 `_consecutive_negative` 计数器，追踪连续攻击次数
2. 修复情绪分析 bug：分析用户输入而非 AI 回复（从 short_term 取最后一条 user turn）
3. 累积伤害放大：`sentiment *= 1.0 + consecutive * 0.4`
4. 正面互动降计数器：`sentiment > 0.1` 时 `consecutive -= 1`
5. 将 `consecutive_negative` 传入 `build_system_prompt`

### prompts/system.py

三级破防指令：

| 连续次数 | 状态 | 行为 |
|---------|------|------|
| 1-2 | 被怼了一下 | 轻回怼，不在意 |
| 3-4 | 有点受伤 | 委屈，底气不足 |
| 5+ | 破防 | 哭腔、反问、撒娇式回击 |

参考语气示例内嵌到 prompt 中，引导 LLM 表现出对应情绪。
